# Graphgen
Programa em python que desenha graficos a partir de arquivos CSVs no computador do usuário

Para executar este programa Python, é necessário que o usuário tenha o Python instalado em sua máquina. 
download Python: https://www.python.org/downloads/

Após instalação, é necessário adicionar o caminho do Python às Variáveis de ambiente do sistema operacional.

Para a execução correta do programa, é necessário instalar pacotes extras que trabalham com a geração de gráficos, sendo eles Pandas, MatPlotLib e Seaborn.
Abra um terminal e digite ou cole o comando: pip install pandas matplotlib seaborn

Caso o comando não seja reconhecido, tente executar uma das opções abaixo
python -m pip install pandas matplotlib seaborn
py -m pip install pandas matplotlib seaborn

Por fim, coloque os arquivos .csv na mesma pasta do programa e execute o terminal nesta pasta via gerenciador de arquivos ou editor de código (ex: Visual Studio Code)
digite no terminal:
python gerador.py
ou
py gerador.py

Caso os comandos não sejam reconhecidos, reveja a etapa de adicionar o Python às Váriaveis de Ambiente
